# Tracks (Phoenix v2)

Phoenix v2 is a *pattern* not an AWS-only thing.

Track idea:
- A "canon" defines subject (e.g., phoenix-protocol-secure-cloud-operator).
- A "version" defines the contract (v2).
- An "archetype" defines the tool domain (aws | azure | gcp | linux | network | security).

Examples:
- AWS Operator v2 (archetype=aws)
- Linux Operator v2 (archetype=linux)
- Network Operator v2 (archetype=network)
- Security Foundations v2 (archetype=security)
