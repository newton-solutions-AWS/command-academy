# Phoenix Protocol v2 — Operational Tracks

Phoenix Protocol v2 is structured into deterministic operational tracks.

## Track 1 — Identity & Access
- AWS STS identity verification
- IAM role visibility
- Permission boundary awareness

## Track 2 — Storage
- S3 bucket visibility
- Read-only access validation
- Empty-environment handling

## Track 3 — Compute
- EC2 instance visibility
- Lambda function listing

## Track 4 — Networking
- VPC visibility
- Subnet enumeration
- Security group inspection

## Track 5 — Observability
- CloudWatch alarms
- Metrics visibility
- Log access verification

## Track 6 — Multi-Cloud (Future)
- Azure read-only CLI
- GCP read-only CLI
