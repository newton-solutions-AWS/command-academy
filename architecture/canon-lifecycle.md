# Canon Lifecycle Specification

## Lifecycle States
1. Draft
2. Generated
3. Audited
4. Approved (GOLD)
5. Mounted
6. Completed
7. Certified

## Rules
- No canon may be mounted without audit approval
- Canon versions are immutable
- New versions require re-audit

## Example
phoenix-protocol-secure-cloud-operator v2 → GOLD → Mounted
